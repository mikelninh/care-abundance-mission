# OpenWork V0

Static interactive prototype: open `index.html` in a browser.

The prototype demonstrates:

- worker view with only GREEN/startable missions;
- practical Skill Passport qualification;
- €20+/hour OpenWork Fair Floor;
- funding states RED/YELLOW/GREEN;
- requirement for binding coverage **and** payroll liquidity;
- job-transition gate at 120 paid hours or 12 recurring weeks;
- visible progression above the floor.

This is a product/logic prototype, not a live employment marketplace or payroll service.
